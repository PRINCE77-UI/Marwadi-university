# 🎓 Marwadi University Website

A modern and responsive university website designed for **Marwadi University, Rajkot** using **HTML, CSS, Bootstrap, and JavaScript**.

The website provides a clean and interactive interface for students and visitors to explore university information, academic programs, campus activities, recruiters, testimonials, FAQs, and contact information.

---

## 🌐 Project Overview

This project is a frontend-based university website created to demonstrate modern web design, responsive layouts, Bootstrap components, navigation, modals, image galleries, forms, and interactive UI elements.

The homepage presents **Marwadi University Rajkot** with the tagline:

> **Innovation | Excellence | Leadership**

---

## ✨ Features

* 🏫 University introduction and About Us section
* 📚 Courses and academic programs section
* 🎯 Vision, Mission & PSO tabs

* 🏢 Top recruiters section
* 💬 Student testimonials carousel
* ❓ Frequently Asked Questions (FAQ)
* 📩 Contact Us section with contact form
* 🔐 Student Login modal
* 🔔 Notification offcanvas panel
* 🔎 Search bar
* 📱 Responsive navigation menu
* 🎨 Bootstrap-based responsive UI
* 🖼️ Responsive images and gallery

The navigation provides quick access to About, Courses, Vision & Mission, Gallery, Recruiters, FAQ and Contact sections.

## 📄 Website Sections

The homepage introduces **Marwadi University Rajkot** with an "Explore Programs" call-to-action.

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/PRINCE77-UI/marwadi-university.git
```

### 2. Open the project

```bash
cd marwadi-university
```

### 3. Run the website

Open:

```text
index.html
```

in any modern web browser.

### Recommended

For a better development experience, open the project in **Visual Studio Code** and use the **Live Server** extension.
